# iOS 6 theme font

`smarttubetv/src/main/res/font/ios6_sans_regular.otf` and `ios6_sans_bold.otf` are
**TeX Gyre Heros** 2.004 (`texgyreheros-regular.otf`, `texgyreheros-bold.otf`),
by B. Jackowski and J. M. Nowacki for the TeX users groups. It is a free
Helvetica-style typeface, which is the closest legal match for the iOS 6 system font.

The fonts are unmodified. They were renamed only because Android resource names
must be lowercase identifiers. They are distributed under the GUST Font License
(`GUST-FONT-LICENSE.txt`, LPPL 1.3c or later).
Source: https://www.gust.org.pl/projects/e-foundry/tex-gyre/heros

Coverage is Latin and Greek. Text in other scripts (Cyrillic, CJK, Arabic, ...)
falls back to the system font automatically.
